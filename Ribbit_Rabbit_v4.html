📥 Import Rosters

Option A — Paste simple JSON

Paste a JSON with class names and student names. First word = first name, rest = last name. Works with names from PowerSchool, class lists, etc.

Example format (click to copy): {"classes":[ {"className":"Kb","students":["Aarav-Akkineni","Lena-Inoue","Sri Parnita-Rapolu"]}, {"className":"Kc","students":["Arthur-Luo","Diya-Pahare"]} ]} Use a hyphen (-) between first and last name. Multi-word first names work: "Sri Parnita-Rapolu"
Option B — Use AI to extract from a school PDF

Copy the prompt below, paste it into any AI chat (ChatGPT, Gemini, Claude), and upload your attendance PDF. The AI returns JSON you paste here.

IMPORTANT: This contains confidential student information. Do not store, share, or reference any student names outside this conversation. Delete this conversation when finished. I am uploading class attendance audit PDF(s). For EACH class, extract: 1. The "Course" name (e.g. "Movement K") — use this as "className" 2. The "Section" number — use this as "period" 3. EVERY student listed Student names may be "LastName, FirstName MiddleName" (comma format) or "FirstName LastName" (no comma). - If there IS a comma: firstName = first word after the comma. lastName = word(s) before the comma. - If there is NO comma: firstName = first word. lastName = remaining words. Count EVERY student. Verify your count. Include students marked N/E. Output ONLY this JSON, no markdown, no explanation: {"classes":[{"className":"Movement K","period":"1","totalStudents":33,"students":[{"firstName":"Aludra","lastName":"Afrah"},{"firstName":"Aarav","lastName":"Akkineni"}]}]} Rules: - Include EVERY student - firstName = ONLY the first name - Multiple classes go in the "classes" array - Double-check your count matches totalStudents
⚠️ Always double-check your roster after import

🔊 Bluetooth Speaker Fix

If your Bluetooth speaker sleeps and misses the first sound, turn this on. A tiny near-silent tone plays first to wake it up, then the real sound plays a moment later. You can also make any single sound play twice — edit that sound and turn on "Play Twice."

🔔 Attendance Sounds

Pick a sound for marking Present or Absent. Leave as "Auto chime" for a simple built-in tone. The Absent sound is a good cue that lets students know they didn't speak up when called.

🏅 Badges

Upload badge images (leader badges, stars, etc.) to award to students. Assign them from a student's edit screen in Attendance.

💾 Backup & Move to Another Device

One button saves everything into a single .rrbak file (a real archive package). Move that file to your new device (email, AirDrop, USB, cloud folder), then Import it.

✓ What's in your backup: Sounds (audio + images) · Rosters + student photos + badges · Playlists · Timer presets · Group sets · Attendance history · Notes · All your settings (master volume, wake-speaker, celebration sound, attendance sounds)

⚠ What doesn't transfer: Bluetooth speaker pairing (that's your device's OS, not the app) · Browser cache. Everything else moves.
