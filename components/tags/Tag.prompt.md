Small rounded label for grade level, subject, and "Free" / "New" status.

```jsx
<Tag variant="accent">New</Tag>
<Tag variant="primary">Grades 3-5</Tag>
<Tag variant="outline">Math</Tag>
```

Variants: `accent` (sun yellow, for "New"/"Free" status), `primary` (lily green tint, for subject/grade taxonomy), `neutral`, `outline` (for filter chips not currently selected).
