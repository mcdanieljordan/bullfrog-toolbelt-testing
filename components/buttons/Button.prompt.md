Pill-shaped call-to-action button, used for "Visit Tool", "Submit a Tool", nav CTAs.

```jsx
<Button variant="primary" size="md">Visit Tool</Button>
<Button variant="secondary" size="sm">Save</Button>
<Button variant="ghost">Cancel</Button>
```

Variants: `primary` (solid lily green, for the one main action per view), `secondary` (soft mud-brown tint, for supporting actions), `ghost` (outlined, for tertiary/cancel actions). Sizes: `sm`, `md`, `lg`. Disabled drops to 45% opacity.
